# Dataset Card: procedural-tones-speech-pairs-v1

## Purpose

P24 audio-text alignment and bounded recognition gate. This is a procedural
transcript task, not a real speech or speaker benchmark.

## Provenance

Waveforms are generated by `src/hai/models/audio.py`; transcript labels and
source-safe group splits are generated by `src/hai/models/speech.py`. No
external audio, voices, transcripts, or pretrained weights are used.

## Pairing and splits

Each tone class maps to one transcript token: `low`, `midlow`, `midhigh`, or
`high`. Four consecutive examples form one source group. Whole source groups
are assigned to TRAIN, VALIDATION, or TEST, preventing source overlap between
development and evaluation.

## Metrics and limitations

Alignment uses class-aware recall@1 because repeated class transcripts are
valid positives. ASR reports exact transcript accuracy and one-token WER.
This synthetic task validates provenance, alignment, decoding, and WER
plumbing; it does not measure natural speech recognition.
