# ADR-0003: Require M2 core ablation before adding perception

## Context
Adding vision/audio before proving routing, verification, and evaluation would create too many simultaneous research/debug variables.

## Decision
P14/M2 must be evaluated before P15+ expansion. If the heterogeneous core shows no value, perform root-cause analysis before building multimodality.

## Consequences
The project stays scientifically interpretable and novice-manageable.
