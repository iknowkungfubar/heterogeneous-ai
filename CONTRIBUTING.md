# Contributing

Contributions are welcome when they preserve the project's experimental integrity.

Before opening a change:

1. Read `AGENTS.md` and the relevant phase/architecture documents.
2. Keep changes narrowly scoped and testable.
3. Add or update tests.
4. Do not add pretrained neural artifacts to the scratch-training path.
5. Document new datasets, licenses, and provenance.
6. For a major architecture change, add an ADR.
7. For empirical claims, include reproducible experiment evidence rather than subjective output examples.

Use conventional, descriptive commits where practical. Do not commit generated large checkpoints or datasets.
